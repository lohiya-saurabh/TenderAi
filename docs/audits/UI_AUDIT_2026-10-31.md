# UI audit — 31 Oct 2026

Scope: every page of `apps/web` in light and dark mode at 1440 px and 375 px, on a seeded bid with 9 clauses and 2 conflicts (golden extraction event through the real webhook, demo database). 144 captures. Each capture records a full-page screenshot, horizontal overflow, the font size of every heading, control and chip, and axe `color-contrast` (WCAG AA).

Pages: landing, pricing, login, sign-up, bids, new bid, bid overview, clause workspace (list, open clause, verify layout), conflicts, checklist, audit trail, company profile (all tabs, evidence vault), settings (all tabs), profile, company menu, user menu, upload dialog.

## Type scale (target)

| Role                                   | Class                            | Size       |
| -------------------------------------- | -------------------------------- | ---------- |
| Page title (`h1`)                      | `text-2xl font-semibold`         | 24 px      |
| Section title (`h2`)                   | `text-base font-semibold`        | 16 px      |
| Card title (`h3`)                      | `text-sm font-semibold`          | 14 px      |
| Body                                   | `text-sm`                        | 14 px      |
| Secondary, meta, labels, table headers | `text-xs`                        | 12 px      |
| Chips                                  | `text-2xs` (sm) / `text-xs` (md) | 11 / 12 px |
| Controls in forms                      | `text-sm`, `h-9`                 | 14 px      |
| Controls in toolbars and filter bars   | `text-xs`, `h-8`                 | 12 px      |

Marketing heroes (landing, pricing) are exempt for `h1`/`h2`. Uppercase is not used for labels; `font-mono` only for identifiers (tender ID, GSTIN, clause number, page reference).
